# Shift Board - 松戸店シフト管理システム

Flaskベースのシフト管理Webアプリケーションです。

## セットアップ

```bash
pip install -r requirements.txt
python app.py
```

ブラウザで http://localhost:5000 にアクセスしてください。

## 機能

### 店長機能
- シフト表の作成・編集（ExcelライクなグリッドUI）
- 従業員の配置管理
- 売上データの入力・管理
- 部長への提出用レポート生成（印刷対応）
- 労働統計の自動計算

### アルバイト機能
- 出勤可能日の入力
- 確定シフトの閲覧

### データ管理
- 従業員情報の管理（高校生の時間制限など）
- LINEメッセージの監視・紐付け
